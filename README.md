# 🏫 생성형 AI 개념 퀴즈 & 자가진단 시스템 (예비 교사 대상)

본 웹 어플리케이션은 교직을 이수하는 대학생(예비 교사)을 대상으로 **생성형 AI의 기본 개념**을 학습하고 성찰하도록 돕는 교육용 퀴즈 및 자가진단 도구입니다.

초보자도 소스코드를 직관적으로 파악하고 고칠 수 있도록 군더더기 없는 구조로 설계되었으며, 구글 스프레드시트와의 완벽한 연동을 통해 실시간 문제 업데이트 및 평가 결과 수집을 지원합니다.

---

## 🚀 주요 기능
1. **정밀 개념 진단**: 생성형 AI 기본 개념, 할루시네이션, 프롬프트 엔지니어링(Few-shot), 교사 지도 원칙, 저작권 및 윤리에 관한 핵심 5문항 진단.
2. **구글 스프레드시트 연동 (선택형)**:
   - 스프레드시트에서 실시간 문제 다운로드 (커스텀 문제 출제 가능)
   - 학생들의 결과(별명, 점수, 성찰 일지)를 스프레드시트에 저장
3. **학습 성찰 일지(Reflection)**: 단순 문제 풀이를 넘어 예비 교사로서 교실에서 이를 어떻게 환류하고 지도할지에 대한 성찰 일지 수집 기능 제공.
4. **아름다운 반응형 UI & 인터랙션**: Tailwind CSS 및 Framer Motion을 결합한 세련되고 따뜻한 교육용 피치 Slate 테마와 마이크로 인터랙션 구현.

---

## ⚙️ 구글 스프레드시트 연동 방법 (배포 후 진행)

어플리케이션이 완성된 후, 실시간 스프레드시트 연동을 하려면 다음 단계를 수행하세요:

1. **연동 설정 가이드 확인**:
   - 프로젝트 루트 폴더 안의 `appscript.md` 파일을 엽니다.
   - 가이드라인에 적힌 Google Apps Script 코드를 복사하여 구글 스프레드시트의 도구에 설정하고 배포합니다.
2. **웹앱 URL 복사**:
   - 배포 결과로 지급받은 웹앱 주소(`https://script.google.com/macros/s/.../exec`)를 복사합니다.
3. **어플리케이션에 URL 등록**:
   - 실행 중인 웹 어플리케이션 화면 우측 상단의 **설정 아이콘(⚙️)**을 누릅니다.
   - 복사한 **Apps Script Web App URL** 필드에 주소를 붙여넣고 저장합니다.
   - "스프레드시트 실시간 연동 활성화" 스위치를 켜면 연동이 시작됩니다!

*(참고: 스프레드시트 연동을 설정하지 않아도, 애플리케이션 내장 디폴트 퀴즈 데이터와 로컬 세션 저장을 통해 즉시 완벽한 작동을 체험해 볼 수 있습니다.)*

## 📂 파일 구조
* `/src/types.ts`: 문제 및 결과 데이터 타입 정의
* `/src/data/defaultQuestions.ts`: 내장형 퀴즈 데이터셋 (생성형 AI 기본 개념)
* `/src/components/QuizStart.tsx`: 자가진단 전 별명/닉네임 입력 및 유의사항 화면
* `/src/components/QuizPlay.tsx`: 퀴즈 풀이 진행 (3~5개 엄선된 문제의 입체적 레이아웃)
* `/src/components/QuizFeedback.tsx`: 퀴즈 채점 결과, 정답 해설 및 예비교사 성찰 일지 작성/스프레드시트 전송 화면
* `/src/components/SettingsPanel.tsx`: Apps Script Web App URL 설정 및 통신 상태 진단 패널
* `/src/App.tsx`: 핵심 라우팅 흐름 및 상태 관리 코어
* `/appscript.md`: 구글 스프레드시트 설치용 Apps Script 소스코드 및 친절한 매뉴얼
